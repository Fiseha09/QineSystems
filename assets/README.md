# Assets Directory

## Logo Integration

Place your **Qine Systems logo** in this directory with the filename:

```
qine-logo.png
```

### Recommended Logo Specifications:

- **Format**: PNG with transparent background (recommended) or SVG
- **Dimensions**: 400px width × 400px height (or proportional)
- **File Size**: < 50KB for optimal loading
- **Color Mode**: RGB with transparency

### Alternative Formats Supported:

If you prefer other formats, you can also use:
- `qine-logo.svg` (vector format, scales perfectly)
- `qine-logo.jpg` (if background is required)
- `qine-logo.webp` (modern format, better compression)

### Where the Logo Appears:

1. **Header Navigation**: Top-left corner alongside "QINE SYSTEMS" text
2. **Footer**: Bottom section with branding

### CSS Styling Applied:

The logo automatically receives:
- Responsive sizing (40px height on desktop, 32px on mobile)
- Electric violet glow effect
- Hover animations (scale + enhanced glow)
- Proper spacing and alignment

### If You Don't Have a Logo Yet:

The site will gracefully fallback to showing only the "QINE SYSTEMS" text. The `onerror="this.style.display='none'"` attribute ensures no broken image icons appear.

### Creating Your Logo:

**Design Tools:**
- [Canva](https://www.canva.com) - Free, easy logo maker
- [Figma](https://www.figma.com) - Professional design tool
- [Logo Maker](https://www.logomaker.com) - Quick logo generation

**Color Palette for Logo Design:**
- Deep Indigo: `#1E1B4B`
- Electric Violet: `#6D28D9`
- Cyber Neon Blue: `#06B6D4`
- Radiant Gold: `#D97706`

**Logo Style Recommendations:**
- Modern, geometric shapes
- Tech/coding theme (consider: brackets { }, binary digits, circuit patterns)
- Clean lines that work at small sizes
- High contrast against dark backgrounds

**Note**: Once you add your logo file, refresh your browser to see it appear on the website!
